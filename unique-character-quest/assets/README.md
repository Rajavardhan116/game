# Assets Directory

This directory is designated for static artwork, game logos, badges, and documentation diagrams for **Unique Character Quest**.

## Audio Notice
The application uses the browser's native **HTML5 Web Audio API** oscillator synthesizer (implemented in `frontend/components.py`). This guarantees:
1. Instant zero-latency 8-bit arcade audio chimes and fanfares.
2. 100% legal, royalty-free synthesized waveforms.
3. No reliance on external MP3 or WAV files that could trigger 404 errors.
4. Seamless offline gameplay capability.
